# Design Validation

A Penpot design is valid only when:

1. Every surface maps to an approved requirement.
2. Components are reusable where repetition exists.
3. Semantic tokens are used instead of arbitrary visual values.
4. Confidence, validation, and failure states remain visible.
5. No design element changes the underlying research conclusion.
6. A disconnected Penpot runtime is reported as `DESIGN_SPEC_ONLY`.

## Required artifact
Return:

- design specification
- requirement IDs
- component inventory
- token inventory
- validation status
- unresolved issues
