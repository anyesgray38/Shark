# Shared Research Rules

1. Facts, interpretations, hypotheses, and conclusions must remain distinct.
2. Every dataset has provenance and a quality status.
3. No look-ahead leakage.
4. No cherry-picked validation windows.
5. Include realistic transaction costs and slippage.
6. Report uncertainty and failure cases.
7. Prefer falsification over confirmation.
8. Production promotion requires explicit validation.
9. Live trading remains disabled by default.
