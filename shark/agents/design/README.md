# SHARK Design Agent

The Design Agent converts validated Shark requirements into design-system primitives, Penpot specifications, implementation contracts, and validation artifacts.

## Control hierarchy

1. `AGENT.md` — agent contract
2. `design-system.md` — visual-system rules
3. `penpot.md` — Penpot integration rules
4. `workflow.md` — execution sequence
5. `../shared/design_rules.md` — cross-agent design constraints

## Principle

Design is downstream of validated requirements. Visual polish must never imply statistical confidence that the research has not earned.
